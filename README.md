Tibbou: Data Lineage and Cost Management

**Welcome to Tibbou** 

Tibbou is a web-based application that helps data teams understand where their
datas comes from and monitor cloud data costs. The goal of this system is to
improve visibility, reduce unexpected expenses, and support informed decision
making for data engineers and analysts.

Tools and Technologies used;

FastAPI, Supabase, CodeRabbit, React, AWS Amplify
